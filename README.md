# AI-Based Online Examination System

## Project Description
This project is an AI-Based Online Examination System developed using Python, HTML, CSS, JavaScript and AWS Cloud Services.

## Objectives
- Online student examination
- Secure student login
- Display multiple-choice questions
- Automatic answer evaluation
- Generate examination results

## Technologies Used
- Python
- HTML
- CSS
- JavaScript
- AWS Cloud Services

## AWS Services
- Amazon S3
- AWS Lambda
- Amazon API Gateway
- Amazon DynamoDB
- Amazon Cognito
- Amazon CloudWatch
